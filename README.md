# Introducão ao HTML

HTML é uma linguagem para criar estruturas de páginas web.

## Principais elementos
## Titulos
Os elementos **h1** até **h6** são usados para títulos e subtítulos

### Paragrafo
O elemento **p** é usado para criar parágrafos.

### Links
O elemento **a** cria links para outras paginas.

### Imagens
O elemento de **img** é usado para adicionar imagens.
